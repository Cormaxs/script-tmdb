# TMDB - The Movie Database

Aplicación Node.js para interactuar con The Movie Database (TMDB).

## Instalación

```bash
npm install
```

## Uso

Para iniciar la aplicación:

```bash
npm start
```

Para usar modo de desarrollo con reinicio automático:

```bash
npm run dev
```

## Descripción

Este proyecto está diseñado para trabajar con la API de The Movie Database (TMDB).

## Requisitos

- Node.js v16 o superior
- npm o yarn
